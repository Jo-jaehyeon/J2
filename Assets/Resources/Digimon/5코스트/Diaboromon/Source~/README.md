# Diaboromon

Low-poly Blender asset integrated into J2.

- Four Legacy clips: Idle, Walk, Attack, Death.
- Native editable source: Diaboromon.blend.
- Unity uses the sibling FBX, materials, clips and prefab.
- manifest.json records dimensions, palette and original reference hashes.
- validation.txt and runtime-validation.txt contain passed checks.
- Reference triplet removed after successful verification on 2026-09-13.
- Import/reimport via DigimonBlenderAssetBuilder.BuildAvailable() in Edit mode.

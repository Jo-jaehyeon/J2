# C# readability tool

Run from the J2 root with the installed .NET 9 SDK:

```powershell
dotnet run --project Tools/CodeStyle -- .
```

Processes authored `Assets/**/*.cs`. Skips `<auto-generated>` and `.g.cs` sources. Adds statement-body braces using Roslyn syntax trees, normalizes whitespace, and separates methods and statement groups. It checks parsing and preservation of all non-brace tokens for UNITY_EDITOR/DEVELOPMENT_BUILD, ARENA_HEADLESS and player configurations before writing each file. It uses Roslyn supplied by the local SDK; no external NuGet package is required.

Review semantic logic boundaries manually after running. In particular keep packet construction separate from sending, even when originally embedded in a single call. Compile in Unity and run relevant behavior checks after changes. Do not run while another editor or agent is rewriting the same files.
MemberLayout groups member fields by project/basic/Unity type and aligns the first declared name with literal tabs (tab width 4). Initializer evaluation order and detected field dependencies are preserved; unsafe reorderings retain original order. This pass runs after whitespace normalization so tabs are retained.

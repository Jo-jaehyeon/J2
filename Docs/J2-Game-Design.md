# J2 통합 기획서

개정일: 2026-09-13  
상태: 기존 설계 유지 사항과 이번 세션의 확정 변경 사항을 통합한 기준 문서. 기물 후보군은 삭제했으며 재선정 전까지 비워 둔다. 코스트·별 합성·판매 환급·판매 재고 반환·역할군 필드·NoData 명칭·별 이미지 UI는 코드와 데이터에 반영했다. 2골드 전체 리롤도 적용했다. 최대 레벨 10은 후속 구현 대상이다.

## 1. 기획 방향과 적용 기준

J2는 디지몬을 소재로 하는 오토배틀러다. 기물 구매, 별 강화, 타입·속성 상성, 조합과 배치를 통한 전투 판단을 중심으로 한다. 진화는 이 구조를 바탕으로 추후 별도 설계한다.

이 문서의 상태 표시는 다음을 뜻한다.

- **기존 유지:** 현재 프로젝트의 문서·코드·저장 데이터에서 확인했으며 이번 논의로 바꾸지 않는 규칙.
- **변경 확정:** 사용자가 이번 세션에서 선택한 방향. 현재 구현과 다를 수 있다.
- **미정:** 아직 정하지 않은 수치·세부 규칙. 이전 답변의 제안을 확정 사항으로 간주하지 않는다.

사용자의 최신 결정이 기존 구현보다 우선한다. 그 밖의 수치는 현재 저장 데이터와 실제 규칙 코드를 기준으로 기록한다. 코드의 초기 기본값, README의 과거 설명, 실제 JSON 값이 다르면 혼동하지 않도록 구분한다.

## 2. 기물 분류

### 타입 — 기존 유지

타입은 다음 6개다.

- 언노운
- 백신
- 데이터
- 바이러스
- 프리
- NoData

NoData는 타입이다. 속성의 무속성과는 서로 다른 개념이다. 코드 enum, UI, 문서에서 NoData로 통일한다. 기존 직렬화 값 5는 유지한다.

### 속성 — 기존 유지

속성은 불, 풀, 물, 전기, 바람, 땅, 어둠, 빛, 무속성의 9개다.

공격 측에서 우위를 갖는 방향:

- 불 → 풀 → 물 → 불
- 전기 → 바람 → 땅 → 전기
- 어둠 ↔ 빛
- 무속성은 속성 우위·열위 없음

기존 코드의 Neutral 및 표시명 '무'가 무속성에 해당한다. 원형 상성을 임의로 역방향 피해 감소로 해석하지 않는다. 현재 규칙은 유리한 방향의 추가 피해만 존재한다.

### 역할군 — 변경 확정

타입·속성과 별개로 다음 5개 역할군을 사용한다.

| 역할군 | 전투에서 담당하는 기능 |
|---|---|
| 수호 | 전열 유지, 피해 흡수, 아군 보호 |
| 투사 | 근접 공격과 지속 전투 |
| 사수 | 기본 공격 중심의 지속 피해 |
| 술사 | 스킬 중심의 피해 |
| 지원 | 회복, 보호막, 아군 강화 |

역할군의 채택과 역할군 시너지의 구체적인 효과·발동 수는 별개의 결정이다. 이전에 제안한 자동 회복, 마법 저항, 2/4/6 발동 등의 수치는 확정하지 않는다. 현 전투 스탯에는 별도 마법 저항이 없으므로 문서에서 임의로 추가하지 않는다.

제어·약화는 개별 스킬 효과로 활용할 수 있으나 별도 역할군으로 분류하지 않는다. 물리/특수 공격 구분 역시 역할군과 별개다. 술사라는 이름만으로 기존 공격 공식을 바꾸지 않는다.

### 코스트와 별 — 변경 확정

- 상점 기물은 1~5코스트로 구분한다.
- 각 기물은 독립적인 구매·강화 대상이다.
- 원작 진화 단계는 캐릭터 정보이며 코스트와 일대일 대응하지 않는다.
- 별은 1성·2성·3성으로 구분한다.
- 타입·속성·역할군·코스트·별을 서로 다른 정보로 관리한다.
- 별 강화 시 같은 디지몬을 유지하고 기본 사거리, 타입, 속성, 핵심 역할이 바뀌지 않는다.

이전 기획안의 별도 8개 계열 분류는 사용하지 않는다. 기존 타입·속성을 대체하거나 추가 계열을 자동으로 도입하지 않는다.

## 3. 상성 및 피해 계산 — 기존 유지

### 타입 상성

| 공격 타입 → 방어 타입 | 타입 배율 |
|---|---:|
| 백신 → 바이러스 | 2 |
| 바이러스 → 데이터 | 2 |
| 데이터 → 백신 | 2 |
| 언노운 → 백신·바이러스·데이터 | 1.1 |
| 백신·바이러스·데이터 → NoData | 1.1 |
| 공격자 또는 방어자가 프리 | 1 |
| 그 밖의 조합 | 1 |

프리는 타입 상성만 중립이다. 별도로 보유한 속성의 배율까지 무효화하지 않는다. 언노운 → NoData는 별도 우위가 지정되지 않았으므로 1배다.

### 속성 상성

앞서 명시한 우위 방향은 1.5배, 그 밖의 방향은 1배다. 빛과 어둠은 서로 공격할 때 모두 1.5배다. 무속성과 관련된 속성 배율은 1배다.

### 피해 공식

```text
피해 = 공격 수치 × 스킬 배율 × 100 / (100 + DEF) × 타입 배율 × 속성 배율
```

- 물리형은 ATK, 특수형은 INT를 공격 수치로 사용한다.
- 현재 기본 공격과 공통 특수 공격은 같은 공격 구분을 사용한다.
- 기본 공격의 스킬 배율은 1이다.
- DEF는 현재 물리형·특수형 양쪽 피해에 적용된다.
- DEF 100이면 방어 적용 전 피해의 절반이 된다.
- 타입 우위 2배와 속성 우위 1.5배가 함께 적용되면 상성 부분은 3배다.
- 유리하지 않은 방향에 0.5배 등의 별도 불리 배율을 추가하지 않는다.

## 4. 기물 능력치와 스킬

### 기존 유지

- HP: 최대 체력.
- SP: 특수 공격에 필요한 최대 자원.
- ATK: 물리 공격 수치.
- DEF: 피해 감소에 사용하는 방어 수치.
- INT: 특수 공격 수치.
- SPD: 이동 속도. 공격 속도가 아니다.
- 기본 공격 사거리: 정수 1~4칸.
- 공격 구분: 물리형 / 특수형.
- 기본 공격당 SP 획득량, 특수 공격 배율을 기물별 데이터로 조절한다.

SP는 매 전투 0에서 시작한다. 기본 공격마다 설정된 SP를 얻고, SP가 가득 찬 다음 공격에서 특수 공격을 사용한 뒤 0으로 초기화한다. 기본 설정은 최대 SP 100, 공격당 SP 20, 특수 공격 배율 2다. 설정이 달라진 기물은 해당 기물 데이터를 따른다.

현재 구현의 특수 공격은 공통 단일 대상 공격이다. 기존 기물별 수치는 카탈로그에서 관리하며 이번 문서에서 새 후보나 신규 스킬을 배정하지 않는다.

### 별 강화에 맞춰 결정할 항목

- 2성·3성의 HP/ATK/INT 등 강화 배율.
- 별에 따른 스킬 위력 변화.
- 공격 간격의 데이터 기준. 현 구현은 기본 외형 단계가 5 이상이면 0.7초, 그 밖에는 0.95초다. 별 체계 전환 시 외형 단계와 공격 간격의 결합을 어떻게 옮길지 미정이다.
- 역할군별 고유 스킬과 시너지 보너스.

공격 간격·공격 속도를 SPD로 재정의하지 않는다. 현재 스탯과 계산 방식에서 바꾸기로 하지 않은 부분은 유지한다.

## 5. 구매·강화·판매

### 상점 이용 — 기존 유지 + 새로고침 변경 확정

- 라운드마다 후보 5개를 제공한다.
- 보유 골드 안에서 한 번 제공된 후보 중 0~5개를 개별 선택해 구매한다. 새로고침하면 다시 구매할 수 있으므로 라운드 전체 구매량이 5개로 제한되지는 않는다.
- 자동 구매는 하지 않는다.
- 각 후보 슬롯은 한 번만 구매할 수 있으며 구매한 슬롯은 비어 있다.
- 상점 창을 닫고 다시 열어도 후보를 새로 추첨하지 않는다.
- 구매·판매·배치 변경은 준비 시간에 한다. 전투 중 상점은 열람만 가능하다.
- 대기석이 가득 찼을 때의 구매 제한을 유지하되, 즉시 별 합성으로 공간을 확보할 수 있는 예외는 새 합성 조건에 맞게 이관한다.
- 상점에 새로고침 버튼을 제공하며 비용은 1회 2골드다.
- 준비 중이고 2골드 이상 보유했을 때 새로고침할 수 있다. 전투 중에는 사용할 수 없다.
- 새로고침 시 현재 미구매 후보의 예약 재고를 먼저 반환하고, 현재 레벨의 확률과 남은 재고로 후보 5칸을 다시 추첨한다. 구매했던 빈 슬롯도 새 후보를 받을 수 있다.
- 새로고침은 보유 기물에 영향을 주지 않으며, 골드가 허용하는 한 준비 시간 안에서 반복할 수 있다.
- 라운드 시작의 기본 후보 갱신은 무료다. 창을 닫고 다시 여는 동작은 새로고침이 아니다.

### 합성 — 변경 확정

- 동일 디지몬 1성 3개 → 동일 디지몬 2성 1개.
- 동일 디지몬 2성 3개 → 동일 디지몬 3성 1개.
- 3성은 동일 기물의 1성 9개분이며 더 합성하지 않는다.
- 전장과 대기석을 함께 확인해 자동 합성하는 기존 조작 방식을 유지한다.
- 연쇄 합성이 가능하고, 전장 기물이 포함되면 기존처럼 전장 위치를 우선 보존한다.
- 별이 다른 기물끼리는 합성하지 않으며 다른 디지몬으로 교체되지 않는다.
- 별 강화의 이름·사거리·타입·속성·핵심 역할은 유지된다.

### 판매 — 변경 확정

판매 조작은 기존처럼 기물을 화면 하단으로 드래그하고, 예상 판매가를 확인한 뒤 놓는 방식이다. 영역 밖으로 이동하거나 Esc를 누르면 취소한다.

기물의 코스트를 k, 합성 재료의 투자금과 추가 합성 비용을 모두 합한 투자금을 N이라 한다.

- 1코스트는 별과 관계없이 N골드를 반환한다.
- 1성은 코스트와 관계없이 N골드를 반환한다.
- 2코스트 이상·2성 이상은 N - (k - 1)골드를 반환한다. 할인은 최종 판매 시 한 번 적용한다.
- 현재 자동 별 합성의 추가 비용은 0골드이며 재료의 투자금을 합산한다.

| 코스트 | 1성 | 2성 | 3성 |
|---|---|---|---|
| 1 | 1골드 | 3골드 | 9골드 |
| 2 | 2골드 | 5골드 | 17골드 |
| 3 | 3골드 | 7골드 | 25골드 |
| 4 | 4골드 | 9골드 | 33골드 |
| 5 | 5골드 | 11골드 | 41골드 |

위 표는 추가 합성 비용 없이 정가로 구매한 경우다.

골드 환급과 상점 재고 반환은 별개의 규칙이다. 판매 시에는 아래 재고 규칙에 따라 원본 기물 수를 반환한다. 판매가가 할인되어도 반환하는 재고 수는 할인하지 않는다.

## 6. 경제와 플레이어 성장 — 기존 유지 + 최대 레벨 변경 확정

- 시작 플레이어 체력 100.
- 시작 레벨 1, XP 0.
- 별도 시작 골드는 0이며 첫 라운드 기본 수입 2골드를 받아 2골드로 시작한다.
- 1스테이지(1~8라운드) 기본 수입은 라운드당 2골드.
- 2스테이지부터 기본 수입은 라운드당 5골드.
- 이자는 스테이지와 관계없이 라운드 수입 지급 직전 보유 골드로 계산한다.
- 이자 = min(5, floor(보유 골드 / 10)).
- 전투 승리 시 즉시 1골드 지급.
- 3연승째부터 매 승리에 추가 1골드 지급.
- 패배 시 연승 초기화. 현재 연패 보너스는 없다.
- 2스테이지 이후 최대 라운드 관련 수입은 기본 5 + 이자 5 + 승리 1 + 연승 1 = 12골드.
- 4골드로 4XP 구매.
- 전투 종료 시 승패와 관계없이 기본 2XP를 한 번 지급. 최대 레벨에서는 XP를 받지 않는다.
- 필요 XP를 채우면 레벨과 배치 한도 +1. 초과 XP 이월 및 한 번에 여러 레벨 상승 가능.
- 기본 최대 레벨은 10이며 기본 배치 한도는 플레이어 레벨과 같고 최대 10기다.
- 레벨 10에서는 XP 구매와 기본 XP 획득을 중단하며 다음 레벨 진행도를 표시하지 않는다.
- 추후 증강으로 한도를 늘릴 수 있다. 최대 레벨 확장과 배치 수 추가의 구체적인 효과·수치·중첩 방식은 미정이다. 현재 기본 규칙에서는 10을 초과하지 않는다.

후반 수입을 지수적으로 늘리는 이전 2번 대안이나 이자 제거안을 적용하지 않는다.

### 레벨 10 제한에 적용할 필요 XP

레벨은 현재 레벨, XP는 다음 레벨까지 필요한 값이다. 레벨 1~9의 필요 XP는 ArenaBalance.json의 현재 저장값을 유지하고 레벨 10을 최대 레벨로 변경한다.

| 현재 레벨 | 다음 레벨 필요 XP |
|---|---:|
| 1 | 2 |
| 2 | 6 |
| 3 | 10 |
| 4 | 20 |
| 5 | 32 |
| 6 | 40 |
| 7 | 48 |
| 8 | 52 |
| 9 | 64 |
| 10 | 최대 레벨, 다음 레벨 없음 |

기존 데이터의 레벨 10→11 필요 XP 88 및 레벨 11~32 값은 새 기본 진행에 사용하지 않는다. 증강으로 레벨 한도를 확장할 때 사용할 XP·상점 확률은 추후 정의하며 과거 값을 자동 채택하지 않는다.

## 7. 상점 확률과 유한 재고

### 유지할 구조와 판매 반환 변경

- 레벨별 5개 구간 등장 확률을 테이블로 관리하며 각 행 합계는 100%.
- 재고가 있고 후보 종이 존재하는 구간을 추첨한 뒤 그 구간 안에서 기물을 균등 추첨한다.
- 재고가 없거나 기물이 없는 구간은 제외하고 남은 가중치로 추첨한다.
- 추첨 가능한 후보가 전혀 없으면 빈 슬롯이 된다.
- 상점에 후보가 나올 때 재고를 임시 예약한다.
- 구매하지 않은 후보의 예약 재고는 다음 라운드 또는 유료 새로고침 때 반환한다.
- 구매한 기물은 보유하는 동안 해당 재고를 점유한다. 구매 후 영구 소모하는 총량 방식은 판매 반환 방식으로 변경한다.
- 기물을 판매하면 해당 코스트 구간의 공유 재고가 증가한다.
- 반환량은 원본 1성 기물 수 기준으로 1성 1개 / 2성 3개 / 3성 9개다. 동일 기물의 별 합성이므로 모두 원래 코스트 구간에 반환한다.
- 합성 자체로는 재고가 증가하지 않는다. 재료가 점유한 재고를 합성 결과가 그대로 이어받으며, 결과 생성 시 재고를 추가 차감하지도 않는다.
- 예: 2코스트 1성 3개를 구매하면 재고 -3, 2성 합성 시 재고 변화 0, 그 2성을 판매하면 2코스트 재고 +3.
- 같은 구간에 속한 종들은 해당 구간 재고를 공유한다.

판매 반환은 이번에 변경 확정했다. 재고를 종별로 분리하는 변경은 아직 채택하지 않았으므로 기존 코스트 구간 공유 구조를 유지한다. 판매만으로 현재 상점 후보를 다시 추첨하지 않으며, 반환된 수량은 다음 추첨부터 사용한다.

### 코스트 체계로 전환할 부분

현재 5개 구간은 1~5코스트다. 기존 구간별 확률과 공유 재고 구조를 유지하며 판매 반환을 적용했다. 준비 중 2골드 전체 리롤을 적용했다. 아래 숫자는 현행 값 보존을 위한 기준이지 새 기물 규모에 대한 밸런스 검증 결과가 아니다.

### 레벨 1~10 구간별 등장 확률

| 레벨 | 구간 1 | 구간 2 | 구간 3 | 구간 4 | 구간 5 |
|---|---:|---:|---:|---:|---:|
| 1~2 | 100% | 0% | 0% | 0% | 0% |
| 3 | 75% | 25% | 0% | 0% | 0% |
| 4 | 55% | 30% | 15% | 0% | 0% |
| 5 | 45% | 33% | 20% | 2% | 0% |
| 6 | 30% | 40% | 25% | 5% | 0% |
| 7 | 16% | 30% | 43% | 10% | 1% |
| 8 | 15% | 20% | 32% | 30% | 3% |

현재 저장된 재고는 구간 순서대로 **60 / 45 / 35 / 25 / 10**이다. README에 남아 있는 마지막 구간 18은 현 저장값과 다르므로 현재 값 10을 기준으로 한다.

이 수량은 디지몬 후보의 종수가 아니라 공유 구매 재고다. 5코스트 기물 10종이라는 콘텐츠 목표와 별개의 숫자다.

## 8. 전장과 배치 — 기존 유지

- 각 진영 8열 × 4행, 총 32칸.
- 아군은 화면 아래, 적은 위.
- 기본 배치 한도는 플레이어 레벨과 같으며 최대 10기. 추후 증강으로 추가 한도를 제공할 수 있다.
- 양쪽 대기석 각각 10칸. 현재 적 대기석은 멀티플레이 확장을 위한 공간이다.
- 각 기물은 전투 중에도 한 칸을 점유한다.
- 이동 중에는 출발 칸과 도착 칸을 예약한다.
- 기물끼리 겹치거나 통과하지 않는다.
- 상하좌우·대각선 인접 칸으로 이동하며 막힌 모서리를 대각선으로 관통하지 않는다.
- 사거리는 대각선 인접을 포함한 칸 거리로 계산한다.
- 양 진영 사이 철로의 시각적 간격은 사거리 칸 수에 추가하지 않는다.
- 가장 가까운 공격 가능한 적을 우선하며, 사거리와 통로에 따라 공격 가능한 칸으로 이동한다.
- 이동할 통로가 없으면 기다린다.
- 준비 종료 시 배치 한도가 남으면 대기석 왼쪽부터 빈 전장 칸에 자동 배치한다.
- 기존 전장 배치는 유지한다. 대기석이 비어 있으면 현재 배치로 전투한다.

전장 크기 32칸과 배치 한도 10기는 별개다. 전장 크기는 유지하고 그 안에 기본 최대 10기를 배치한다. 증강에 의한 한도 확장의 세부 규칙은 추후 기획한다.

## 9. 용의 눈 호수와 기차 — 기존 유지

밝은 호수, 모래 물가, 숲과 산, 물에 잠긴 송전탑, 초록·크림색 전차가 있는 디지털 월드를 배경으로 한다.

전차는 장식이 아니라 이동과 공격을 막는 전장 장애물이다.

- 준비 시작마다 오른쪽에서 왼쪽으로 1.5칸 이동한다.
- 이동 연출은 약 1.2초.
- 전투 중 위치는 고정된다.
- 전차의 모서리를 돌아 이동해야 하며 원거리 공격도 전차를 관통하지 않는다.
- 전장이 매 라운드 조금씩 달라지므로 통로와 사거리 확보를 보고 배치한다.
- 왼쪽으로 사라진 라운드를 R이라 하면 R+1, R+2에는 없고 R+3에 오른쪽에서 재등장한다.
- 재시작하면 기차 위치를 초기화한다.

메인 화면의 배경은 현재 확정된 아트 상태를 유지한다. 중앙의 작은 섬은 식물 없는 맨땅이고 전차가 놓여 있다. 전투 보드의 이동하는 기차 규칙과 메인 화면 배경 그림은 구분한다.

## 10. 라운드와 PvE 전투 — 기존 유지

### 진행

1. 라운드 시작: 수입 지급, 기차 위치 갱신, 상점 후보 제공.
2. 30초 준비: 구매·판매·2골드 새로고침·XP 구매·배치.
3. 남은 한도 자동 배치 후 자동 전투.
4. 전투 결과 처리: 골드·XP·플레이어 피해.
5. 플레이어 체력이 남으면 4초 후 다음 라운드.

스테이지당 8라운드다. 준비 완료 버튼 없이 시간이 끝나면 전투를 시작한다.

### 승패

- 전투 제한 시간 30초.
- 아군이 생존하고 적이 모두 쓰러지면 승리.
- 아군 전멸 또는 시간 초과는 패배.
- 패배 피해 = 남은 크립 수 × 현재 스테이지 × 2.
- 전투 후 소유 기물은 유지하고 다음 전투에서 체력을 회복한다. SP는 다시 0부터 시작한다.
- 플레이어 체력 0이면 게임 종료 상태.
- 중앙에 '패배했습니다', 아래에 '게임 재시작 / 게임 종료' 버튼 표시.
- 승리 전용 팝업은 표시하지 않는다.
- 재시작하면 체력·골드·XP·소유 기물·재고·기차를 초기화한다.

### 현재 크립 진행

현재 등록된 크립은 스테이지 1부터 차례로 츠메몬 / 케라몬 / 크리사리몬 / 인펠몬 / 디아블로몬 / 아마게몬이다. 이는 기존 PvE 데이터의 기록이며 삭제한 플레이어 기물 후보군과는 별개다.

- 현재 스테이지 이하의 등장 시작 스테이지 중 가장 높은 값을 사용한다.
- 같은 시작 스테이지에 여러 종이 있으면 순서대로 섞어 등장한다.
- 현재 크립 수 = min(8, 1 + floor((스테이지 내 라운드 - 1) / 3) + floor((스테이지 - 1) / 3)).
- 크립 HP/ATK/INT에 현재 배율 0.58 × (1 + (스테이지 - 1) × 0.1 + (스테이지 내 라운드 - 1) × 0.045)를 적용한다.
- 준비 중 적 상세 정보에도 배율 적용 수치를 표시한다.

최종 승리 조건·총 스테이지 제한은 현재 명시되어 있지 않으므로 새로 확정하지 않는다.

## 11. 화면과 조작 — 기존 유지

- 메인 화면에서 싱글 플레이를 선택해야 라운드와 수입·시간이 시작된다.
- 멀티 플레이 버튼은 존재하지만 로비·네트워크 경기는 미구현이다.
- 기물을 좌클릭하면 상세 스탯을 표시한다.
- 대기석 기물을 더블 클릭하면 첫 빈 전장 칸에 자동 배치한다.
- 우클릭 드래그로 전장·대기석 이동 및 기물 위치 교환.
- 드래그 중 Esc 또는 창 포커스 이탈 시 취소.
- 전투 중에는 정보 열람만 가능.
- 전투 중 선택 정보에는 현재 HP/SP를 표시한다.
- 상단은 라운드·시간, 오른쪽은 플레이어 체력, 왼쪽 하단은 골드·레벨.
- 골드·레벨 버튼을 열면 XP 진행도·구매·수입 정보를 표시한다.
- 상점은 라운드 시작에 열리고 전투 시작 시 닫힌다. 별도 버튼으로 열고 닫을 수 있다.
- 상점 상단의 기물 선택·개별 구매 설명 문구를 제거하고 리롤 버튼을 배치한다. 버튼에 비용 2골드를 표시하며 골드 부족 또는 전투 중에는 비활성화한다.
- 상점 위에는 현재 레벨의 구간별 확률을 표시한다. 별 체계 전환 시 표시 기준은 진화 단계에서 코스트로 변경한다.
- 재시작/종료 조작을 유지하며 Editor에서 종료는 Play 모드 종료로 처리한다.

### 타입·속성 배지

- 중앙 기호는 타입을 나타낸다.
- 기호 자체의 색이 속성을 나타낸다.
- 불 빨강 / 풀 연두 / 물 파랑 / 전기 노랑 / 바람 하늘 / 땅 갈색 / 어둠 검정 / 빛 흰색 / 무속성 회색.
- 배경·테두리·가독성 외곽선은 모든 속성에서 동일하다.
- 상점 카드 하단의 코스트·타입 텍스트는 제거한다. 타입·속성은 배지 이미지로, 코스트는 카드 전체 테두리 색으로 구분한다. 구매 골드 표시는 유지한다.
- 타입별 원본 PNG의 기호를 중앙 정렬하고 원형 배지로 표시한다.
- 전장 기물과 상점 초상화는 같은 외형 모델을 사용한다.

기물 상세 정보 최상단에 생성한 금색 별 이미지 1~3개와 코스트·별 수를 표시한다. 전투 중에도 별을 유지한다. 역할군은 공격 구분과 나란히 `물리형 / 사수`처럼 표시한다. 데이터 편집창에서도 공격 구분과 역할군을 나란히 편집한다. 개별 기물 역할 배정은 미정(-1)으로 유지하며 수호·투사·사수·술사·지원 중 선택할 수 있다. 기존 타입·속성 배지를 다른 계열 배지로 대체하지 않는다.

## 12. 데이터 편집·관리 — 기존 유지 및 이관

- 기물 카탈로그에서 고유 ID·이름·외형·스탯·공격 구분·타입·속성·사거리·SP 설정을 관리한다.
- 아군과 크립은 각각 최소 1종 필요하다.
- 외형 프리팹이 없을 때 기본 도형을 사용한다.
- 프리팹은 전장과 초상화 양쪽에서 사용한다.
- 밸런스 테이블에서 레벨별 확률·필요 XP·구간별 재고를 관리한다.
- 저장한 설정은 새 게임부터 적용되며 진행 중인 게임에 즉시 반영하지 않는다.
- 중복 ID·잘못된 수치·누락된 외형 등 데이터 유효성 검사를 유지한다.

이번에 반영한 부분과 남은 이관 항목:

- 적용: cost는 구매 가격 1~5이며 기본 외형 modelTier와 분리한다. 데이터·외형 폴더는 1코스트~5코스트로 정리한다. 기존 기물의 코스트 배정·스탯·외형은 유지한다.
- 적용: 소유 기물의 Stars와 InvestedGold를 보존하고 같은 ID·같은 별로 합성한다.
- 적용: evolvesTo 연결과 유효성 검증을 보존하되 자동 별 합성에서는 사용하지 않는다. 증강·아이템 진화 기능 자체는 추후 구현한다.
- 역할군 5개를 데이터에 반영.
- 새 구매가·판매가·상점 구간 표시 적용.
- 후속: 최대 레벨 10·기본 최대 배치 10 및 레벨 10의 MAX 표시 적용.
- 판매 시 별에 따른 원본 수량 반환, 합성 시 재고 유지 적용.
- 적용: 2골드 리롤 버튼으로 미구매 예약 재고를 반환한 뒤 현재 레벨 확률로 5칸을 재추첨한다. 구매했던 빈 칸도 다시 채운다.
- 기존 진화 연결 검증은 해당 데이터의 사용 여부에 맞게 정리.

현재 JSON의 실제 기물·크립·모델 에셋은 이번 문서 수정으로 삭제하거나 교체하지 않는다.

- 타입·속성에 상성 외의 편성 시너지를 부여할지 여부.
- 증강에 의한 최대 레벨·배치 한도 확장의 수치와 방식, 확장 레벨의 XP·상점 확률.

- 조그레스 도입 여부와 규칙.
- 멀티플레이 및 최종 승리 조건.

이 항목들은 새로 결정하기 전까지 기존 유지 항목을 자동으로 변경하지 않는다.

## 15. 확인한 프로젝트 근거

문서와 구현이 달랐던 부분은 실제 코드·저장 데이터를 확인했다. 코스트·별 이관은 .NET/Unity 규칙 검사 39,608개와 Windows 플레이어 기능 검사로 검증한다. 기존 및 신규 Editor 코드도 컴파일 검사에 포함한다. 전투 밸런스 검수는 수행하지 않았다.

별 UI 이미지의 투명도와 로딩, 전투 중 별·역할군 유지, 이동한 프리팹 경로를 실행 검사한다. 숨김 Windows 플레이어는 UI 렌더링을 생략하므로 화면 배치의 시각 검수는 별도다. 수동 확인용으로 플레이어 실행 시 `-arena-stars-smoke -arena-stars-capture`를 지정하면 1·2·3성과 전투 중 3성 화면을 캡처한다. 숨김 실행에서는 캡처 옵션을 사용하지 않는다.
